# Future developments

After mainnet launch, we plan further phases focused on integrations, expansion, and real-world adoption by firms. Priority stays with community feedback — we will change course when user needs demand it.

## Integrations with dApps and wallets

Integrate inheritance and recovery flows with existing Cardano dApps and wallets where both sides see value, including revenue-sharing models where appropriate.

## Expand compatibility toward Bitcoin DeFi

Pursue paths that connect Bitcoin ecosystems and Cardano (for example efforts in the wider industry around bridging and Bitcoin DeFi) so inheritance and recovery patterns can help Bitcoin holders facing the same lost-key and inheritance problems.

## Real-world adoption by inheritance firms

{% stepper %}
{% step %}
### RWA tokenization for inheritance

Partner with firms that tokenize real-world assets on Cardano and document options so professionals can place tokenized ownership into GenWealth vaults.
{% endstep %}

{% step %}
### Inheritance compliance calculator

A future tool for professionals to evaluate on-chain assets and simulate distributions against jurisdictional rules before committing a will on-chain.
{% endstep %}

{% step %}
### Pilots and continuous improvement

Run pilots with inheritance firms already providing feedback, then expand use cases and regions.
{% endstep %}

{% step %}
### Multi-chain expansion

Crypto inheritance is not Cardano-only. Other chains may reuse patterns via interoperability or need native architectures with the same product goals.
{% endstep %}

{% step %}
### Privacy exploration

Investigate programmable privacy (for example technologies such as Midnight) so sensitive details can stay private until defined triggers.
{% endstep %}
{% endstepper %}

## Community-first approach

We keep close contact with users, gather needs, and build what solves real struggles. Roadmap items above are directions, not promises with fixed dates.
