# Use your wallet with GenWealth

Once your wallet has a little ADA, you can connect it to GenWealth and approve actions.

{% stepper %}
{% step %}
### Open GenWealth and go to Connect your Wallet

You should see the connect screen with the message about securing your family’s digital wealth, and a list of installed wallets (or a prompt to install Eternl, Lace, or Vespr).
{% endstep %}

{% step %}
### Choose your wallet

Click your wallet in the list, or use **Login with Socials** for NuFi. Your wallet extension opens a permission prompt.
{% endstep %}

{% step %}
### Approve the connection

Confirm in the wallet that GenWealth may connect. You are not sending money yet — you are only allowing the site to see your addresses and ask for later approvals.
{% endstep %}

{% step %}
### Approve each later action the same way

When you create a vault, update a will, send assets, or claim, GenWealth builds the action and your wallet asks you to sign. Read the summary in the wallet, then approve only if you intended that step.
{% endstep %}
{% endstepper %}

## If you are a beneficiary or recovery co-signer

You use **your own** wallet the same way. Connect on GenWealth, then follow the claim or recovery screens. You never need the vault owner’s seed phrase.

{% hint style="warning" %}
GenWealth will never ask you to paste a seed phrase. If a page asks for one, leave the site and contact GenWealth support through official channels only.
{% endhint %}
