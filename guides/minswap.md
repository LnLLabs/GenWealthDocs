# Swap and earn with Minswap

From the vault you can use **Minswap** without moving assets to a separate trading wallet first. Open **Minswap** in the sidebar. This feature is available when GenWealth is running on **preprod** or **mainnet** app modes.

## Swap

{% stepper %}
{% step %}
### Open the Swap tab

Choose market or limit style as shown on screen.
{% endstep %}

{% step %}
### Set the pair, amount, and slippage

Slippage presets include **0.1%**, **0.5%**, and **1%** (default is often 0.5%). Review the quote.
{% endstep %}

{% step %}
### Confirm Swap or Place limit

Approve in your wallet. You can cancel open limit orders later from the same area. Executors with **Close DeFi Positions** can cancel orders when helping wind down positions.
{% endstep %}
{% endstepper %}

## Earn (liquidity)

{% stepper %}
{% step %}
### Open the Earn tab

Register as a Minswap owner for the vault if the screen asks you to (sometimes done when the vault was created).
{% endstep %}

{% step %}
### Provide liquidity or withdraw

Follow **Provide liquidity** or withdraw LP tokens as shown. Confirm fees in the wallet prompt before you sign.
{% endstep %}
{% endstepper %}

{% hint style="info" %}
DeFi from a vault still follows your will and recovery rules. Closing positions before inheritance can make distribution simpler — that is why executor **Close DeFi Positions** exists.
{% endhint %}
