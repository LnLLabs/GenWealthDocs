# Future roadmap

Earlier versions of this whitepaper described a phase when V2 was still in UI design. That phase is complete: the application and modular contracts are in active use on public test infrastructure.

1. **Harden on public testnet (preprod)**

    Continue testing vaults, wills, recovery, claims, executors, and DeFi flows with users and professionals. Fix issues found in real usage.

2. **Security audit**

    Commission and complete a security audit of the smart contracts and critical off-chain paths. Resolve findings before a mainnet release.

3. **Mainnet launch**

    Deploy and configure Cardano **mainnet** after audit sign-off, then open the product to mainnet users.

4. **Operate and improve**

    Expand notifications, discovery, and operational reliability; gather feedback from heirs, owners, and firms; refine UX documentation (this book) alongside the app.


Longer-term ideas (multi-chain, firm tooling, privacy) are listed under [Future developments](future-developments.md).
