# Stay safe

A few habits protect most GenWealth users.

## Seed phrase

- GenWealth **never** asks for your seed phrase.
- Write it on paper when you create the wallet. Store it offline.
- Anyone with the seed phrase can move your assets.

## Vault ID

- Write down the vault ID after creation (long code ending with `#` and a number).
- GenWealth cannot recreate a lost vault ID for you.
- Share it only with people who truly need to find the vault (for example a beneficiary or professional you trust).

## Recovery plan

- Prefer several co-signers and a threshold above one.
- Keep recovery inactivity **shorter** than proof of life.
- Make sure co-signers keep a little ADA so they can sign when needed.

## Inheritance

- Once inheritance **starts**, it cannot be cancelled on-chain.
- Choose proof-of-life deadlines you can realistically meet.
- Update the deadline or use the vault when you will be away for a long time.

## Everyday checks

- Only install wallets from official sources.
- Read every wallet approval before you sign.
- Use official GenWealth links and social channels listed in [Socials](../team/socials.md).

!!! warning
    If something feels off — a site asking for a seed phrase, an unexpected ownership change, or pressure to trigger inheritance early — stop and verify through official support before you sign anything.
