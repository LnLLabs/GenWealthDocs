# Set up a blockchain will

A **blockchain will** says who should receive assets from your vault after a period of inactivity (proof of life). You set the rules while you still control the vault. You can edit them until inheritance starts.

Open **Blockchain Will** in the sidebar. If you have not set one up yet, choose **Start Blockchain Will Setup**.

!!! info
    You can have up to **nine** beneficiaries. Shares must add up to 100%. Each share unit is one hundredth of one percent.


## Wizard overview

1. **Time settings**

    Choose how long the vault can stay unused before inheritance can start (**Proof of Life Deadline**). Common presets include **1 Month**, **3 Months**, or a custom length. You can also set related waits used after inheritance starts (executor delay, management period, beneficiary identification stage, and social claim window). Presets are available for each field; custom values use days, months, or years.

2. **Beneficiaries**

    Add each person by a name you recognize and the **wallet address** they control. Assign either a **share** of the remaining vault, **specific assets**, or both. Deploy the will on-chain when the setup asks you to.

3. **Specific assets (optional)**

    Mark particular tokens or NFTs for a beneficiary. You can skip this step if everyone only receives a percentage share.

4. **Executors (optional)**

    Add a trusted person or professional and grant only the permissions they need. You can skip this step. See [Help as an executor](executor-guide.md) for what each permission means. Leave enough ADA in an executor fund if you grant permissions that spend fees on their behalf — the app suggests amounts based on the permissions you tick.


## After setup

The will screen shows tabs: **Inheritors**, **Executors**, and **Settings**. Use them to review or update the plan **before** inheritance starts.

!!! warning
    Once inheritance has started on-chain, you cannot turn it off. Keep your proof-of-life deadline realistic, and use the vault often enough — or update the deadline — so it does not start by accident. Details: [Stay active and understand inheritance phases](stay-active.md).
